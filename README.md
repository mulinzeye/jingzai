# 鲸仔 · 每日行动助手

一个常驻 Windows 桌面角落的日程与提醒小工具：每天给你三条做得完的事，到点用闹钟提醒你，做完打勾。

## 功能

- 每日三条行动，按你的可用时间给量（不是一堆待办清单）
- 定时提醒：到点弹窗 + 人声闹钟，循环响到你点「完成」或「10 分钟后再提」
- 打卡、日记（只增不改，本地保存）
- 隐私模式：一键遮住个人信息区
- 收起后变成桌面角落一枚小圆点，点一下回来
- 可选的传统历法参考（节气、干支），可关闭

## 下载

见右侧 Releases 页面的最新版本。

## 安装

解压后双击 `鲸仔.exe`，不需要安装 Python。数据全部存在本地，不联网、不上传。

## 更新

程序启动后会自动检查本仓库的 `latest.json`。有新版本时，桌面面板会出现红条提示，
点开下载后放进程序目录的 `update` 文件夹，双击 `更新.bat` 即可。
**更新不会覆盖你的 data 与 profiles 目录。**
